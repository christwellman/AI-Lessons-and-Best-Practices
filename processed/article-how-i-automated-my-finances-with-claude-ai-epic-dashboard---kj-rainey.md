## Summary

This video shows how to build a personal finance dashboard inside Claude using a custom plugin. The plugin includes skills for initial setup, monthly updates, and dashboard customization. Users load their bank transaction CSV files into a folder and run slash commands to generate live HTML artifacts that track spending, subscriptions, and budgets.

## Key Takeaways

- Use the Claude desktop application with a paid subscription to access live artifacts.
- Install the finance plugin by dragging the file into a new task chat in Claude.
- Store all financial files and generated artifacts inside a dedicated local folder.
- Run specific commands like  /finance dashboard setup  to initialize the dashboard.
- Review monthly transactions to identify and cancel unwanted subscriptions.
- Use Claude to iteratively modify categories, add tabs, and fix UI bugs via screenshots.

## Techniques / Prompts Extracted

- Install this Claude plugin, please.
- /finance dashboard setup
- /finance new month dashboard
- /finance customization dashboard
