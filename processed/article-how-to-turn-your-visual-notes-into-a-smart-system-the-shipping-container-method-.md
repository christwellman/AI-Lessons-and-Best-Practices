## Summary

The author presents a personal knowledge management system for visual notes called the shipping container method. Notes act as standardized units or shipping containers for ideas that connect into a larger system. Users apply standardization rules, use backlinks to link visual components, and build a four-dimensional knowledge system.

## Key Takeaways

- Treat individual notes as standard shipping containers for single ideas.
- Apply three constraints to visual notes: a card forcing function, a simple color palette, and standard proportions.
- Build visual presentations by placing modular rectangular idea blocks next to each other.
- Use a postcard structure with an image on the front and metadata text on the back.
- Connect visual components across different documents using backlinks in digital tools like Obsidian.
- Shift mindset from using visual thinking as a standalone tool to building an interconnected visual system.
